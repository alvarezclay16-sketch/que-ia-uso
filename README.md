# Qué IA Uso

Directorio en español que dice qué herramienta de inteligencia artificial usar para cada tarea, con opciones gratis.

**Sitio:** https://alvarezclay16-sketch.github.io/que-ia-uso/

Se mantiene solo: un agente de IA revisa novedades todos los días, actualiza los datos (`data/`), regenera el sitio (`scripts/build.py`), lo revisa (`scripts/check.py`) y publica `docs/` en GitHub Pages. Las instrucciones del agente están en [CEO.md](CEO.md).

¿Ves un dato malo? [Avísanos](https://github.com/alvarezclay16-sketch/que-ia-uso/issues/new?title=Dato+incorrecto).
